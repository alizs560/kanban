# ساختار و معماری بک‌اند (Backend Architecture)

بخش بک‌اند پروژه با استفاده از زبان Python، فریم‌ورک FastAPI و ابزار سریع مدیریت بسته `uv` توسعه یافته است و مسئول ارائه APIهای برنامه و سرو فایل‌های استاتیک فرانت‌اند است.

## ساختار پوشه‌ها و فایل‌ها

- `app/`: کدهای اصلی سرویس بک‌اند
  - `__init__.py`: ماژول پایتون
  - `main.py`: نقطه ورود FastAPI، پیکربندی مسیرهای سرویس (`/api/health`)، مستندات خودکار (`/api/docs`) و سرو کامل فایل‌های استاتیک فرانت‌اند از مسیر ریشه `/`
- `static/`: فایل‌های بیلد استاتیک نهایی Next.js 16 (شامل HTML, JavaScript, CSS, دارایی‌های فونت پیدا و آیکون‌ها) که مستقیماً توسط بک‌اند به کاربران ارائه می‌شوند.
- `pyproject.toml`: فایل استاندارد پیکربندی پروژه، وابستگی‌ها و سازگار با `uv`
- `README.md`: راهنمای خلاصه اجرای محلی بک‌اند

## مسیرهای توسعه پیش‌رو (فاز ۵ و ۶)

- پیاده‌سازی پایگاه داده SQLite محلی و ساخت خودکار فایل پایگاه داده در صورت عدم وجود
- ایجاد کاربر پیش‌فرض (`user` / `password`) و مدل‌سازی داده‌ای با ساختار چندکاربره
- پیاده‌سازی اندپوئینت‌های احراز هویت (`/api/auth/login`) و صدور توکن دسترسی
- پیاده‌سازی اندپوئینت‌های تخته کانبان (دریافت، ثبت، ویرایش، حذف و جابه‌جایی کارت‌ها و ستون‌ها)
- اتصال به مدل زبانی OpenRouter (`openai/gpt-oss-120b`) جهت اجرای دستورات متنی کاربر و دستکاری خودکار وضعیت تخته کانبان

## استانداردها و اصول بک‌اند

1. مدیریت پکیج‌ها داخل کانتینر منحصراً با `uv` انجام می‌شود.
2. طراحی و پاسخ‌های API باید ساده، سرراست و بدون افزونگی باشند.
3. در تمام پیام‌ها، داده‌های خروجی و مستندات، هرگز از ایموجی استفاده نمی‌شود.
