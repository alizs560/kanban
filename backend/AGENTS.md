# ساختار و توضیحات بک‌اند (Backend)

بخش بک‌اند پروژه با استفاده از Python، فریم‌ورک FastAPI و ابزار مدیریت بسته `uv` توسعه یافته است.

## ساختار پوشه‌ها و فایل‌ها
- `app/`: کدهای اصلی برنامه بک‌اند
  - `__init__.py`: بسته پایتون
  - `main.py`: نقطه ورود FastAPI، مسیرهای API سلامت (`/api/health`) و مستندات (`/api/docs`)، و سرو فایل‌های استاتیک از مسیر ریشه `/`
- `static/`: فایل‌های استاتیک پروژه که توسط بک‌اند سرو می‌شوند (در فاز فعلی فایل تست `index.html` و در فازهای بعدی بیلد نهایی Next.js)
- `pyproject.toml`: فایل پیکربندی وابستگی‌های پایتون و سازگار با `uv`
- `README.md`: راهنمای خلاصه اجرای محلی بک‌اند

## استانداردها و اصول
- اجرای پکیج‌ها داخل کانتینر با استفاده از `uv`
- عدم استفاده از ایموجی در پاسخ‌ها، گزارش‌ها و کدها
- پایبندی به پالت رنگی و استانداردهای طراحی پروژه
