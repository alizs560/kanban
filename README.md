# LOOM — سامانه مدیریت پروژه و کانبان هوشمند

LOOM یک اپلیکیشن مدیریت پروژه تحت وب شامل تخته کانبان تعاملی، نماهای چندگانه پروژه و دستیار هوش مصنوعی در نوار کناری است. تمام اجزای این برنامه در قالب یک کانتینر داکر اجرا می‌شوند.

## قابلیت‌های کلیدی

- احراز هویت کاربر (نام کاربری `user` و رمز عبور `password`) با معماری پایگاه داده آماده برای چندکاربره شدن
- ستون‌های استاندارد کانبان: «لیست کارها» (To Do)، «در حال انجام» (In Progress) و «تکمیل شده» (Done)
- مدیریت پویای ستون‌ها: افزودن ستون جدید، تغییر نام درجا و حذف ستون با انتقال امن کارت‌ها به ستون اول
- فازهای کاری پروژه (Workflow Phases): تفکیک تسک‌ها بر اساس فازهای هویت بصری، طراحی تجربه، فرانت‌اند، بک‌اند و انتشار، همراه با امکان افزودن، ویرایش و حذف بخش‌ها
- نماهای ۵گانه پروژه (Board Views):
  - تخته (Board): تعاملی با قابلیت کشیدن و رها کردن (Drag and Drop)، جستجو و فرم ویرایش کارت
  - فهرست (List): جدول فشرده تسک‌ها به تفکیک ستون
  - خط زمان (Timeline): گانت‌چارت ۳۱ روزه زمان‌بندی ماهانه وظایف
  - تقویم (Calendar): تقویم شبکه‌ای ماهانه دسامبر ۲۰۲۶ هماهنگ با تقویم فارسی و انگلیسی
  - پیشرفت (Progress): داشبورد تحلیلی پیشرفت پروژه، درصد تکمیل فازها و توزیع اولویت‌ها
- کارت‌های وظایف با پشتیبانی دو زبانه (فارسی و انگلیسی)، اولویت‌بندی (P1, P2, P3)، تخصیص مسئول و پایداری در مرورگر
- اشتراک‌گذاری پروژه با انتخاب سطح دسترسی، دعوت اعضا و کپی لینک
- فرم ویرایش کارت با طراحی مینیمال رترو، زمان‌بندی، اولویت و تصویر کاور
- تایپوگرافی مستقل از اینترنت: فونت محلی پیدا (Peyda) در سه وزن ۳۰۰، ۵۰۰ و ۷۰۰ برای فارسی و فونت سیستمی مدرن برای متون لاتین
- دستیار هوش مصنوعی یکپارچه در نوار کناری با مدل `openai/gpt-oss-120b` (از طریق OpenRouter) با امکان تحلیل، ایجاد، ویرایش و انتقال خودکار کارت‌ها و قابلیت بازگردانی تغییرات (Undo)
- پایگاه داده محلی SQLite با ساخت خودکار جداول و مقداردهی اولیه داده‌ها

## پشته فنی

- فرانت‌اند: Next.js 16، React 19، TypeScript، Tailwind CSS v4، `@dnd-kit`
- بک‌اند: Python، FastAPI، مدیریت بسته‌ها با `uv`
- پایگاه داده: SQLite
- محیط اجرا: Docker ایزوله چندمرحله‌ای

## ساختار مخزن

- `frontend/`: کد منبع رابط کاربری Next.js و کامپوننت‌های نماهای پروژه
- `backend/`: سرویس FastAPI، اتصال دیتابیس SQLite، ارائه فایل‌های استاتیک و ارتباط با OpenRouter
- `scripts/`: اسکریپت‌های راه‌اندازی و توقف کانتینر برای ویندوز (`start.ps1`, `stop.ps1`) و لینوکس/مک (`start.sh`, `stop.sh`)
- `docs/`: اسناد معماری، طراحی مدل داده و نقشه راه توسعه (`PLAN.md`)
- `AGENTS.md`: مشخصات محصول، قوانین و استانداردهای برنامه‌نویسی

## راه‌اندازی سریع

### متغیرهای محیطی
یک فایل `.env` در ریشه پروژه با مقدار زیر تنظیم کنید:
```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

### اجرای برنامه با اسکریپت‌ها
- در ویندوز:
  ```powershell
  .\scripts\start.ps1
  ```
- در لینوکس یا مک:
  ```bash
  ./scripts/start.sh
  ```

مرورگر را در نشانی `http://localhost:8000` باز کنید.

### اجرای تست‌های فرانت‌اند
```bash
cd frontend
npm run test:unit
npm run lint
```
