# LOOM — سامانه مدیریت پروژه و کانبان هوشمند

LOOM یک اپلیکیشن مدیریت پروژه تحت وب شامل تخته کانبان تعاملی و دستیار هوش مصنوعی در نوار کناری است. تمام اجزای این برنامه در قالب یک کانتینر داکر اجرا می‌شوند.

## قابلیت‌های کلیدی

- ورود اختصاصی کاربر (نام کاربری `user` و رمز عبور `password`) با معماری پایگاه داده آماده برای چندکاربره شدن
- تخته کانبان با ۵ ستون ثابت با قابلیت ویرایش نام ستون‌ها
- کارت‌های وظایف با پشتیبانی از دو زبان (فارسی و انگلیسی)، اولویت‌بندی، جستجو و جابه‌جایی با کشیدن و رها کردن (Drag and Drop)
- دستیار هوش مصنوعی یکپارچه در نوار کناری با مدل `openai/gpt-oss-120b` (از طریق OpenRouter) با امکان تحلیل، ایجاد، ویرایش و انتقال خودکار کارت‌ها و قابلیت بازگردانی تغییرات (Undo)
- پایگاه داده محلی SQLite با مقداردهی خودکار داده‌های اولیه

## پشته فنی

- فرانت‌اند: Next.js 16، React 19، TypeScript، Tailwind CSS
- بک‌اند: Python، FastAPI، مدیریت بسته‌ها با `uv`
- پایگاه داده: SQLite
- محیط اجرا: Docker ایزوله

## ساختار مخزن

- `frontend/`: کد منبع رابط کاربری Next.js
- `backend/`: سرویس FastAPI، اتصال دیتابیس SQLite و ارتباط با OpenRouter
- `scripts/`: اسکریپت‌های راه‌اندازی و توقف کانتینر برای ویندوز (`start.ps1`, `stop.ps1`) و لینوکس/مک (`start.sh`, `stop.sh`)
- `docs/`: اسناد معماری، طراحی مدل داده و نقشه راه توسعه (`PLAN.md`)
- `AGENTS.md`: مشخصات محصول، قوانین و استانداردهای برنامه‌نویسی

## راه‌اندازی سریع

### متغیرهای محیطی
یک فایل `.env` در ریشه پروژه با مقدار زیر تنظیم کنید:
```env
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

### اجرای برنامه با اسکریپت‌ها
- در ویندوز:
  ```powershell
  .\scripts\start.ps1
  ```
- در لینوکس یا مک:
  ```bash
  ./scripts/start.sh
  ```

مرورگر را در نشانی `http://localhost:8000` باز کنید.

### اجرای تست‌های فرانت‌اند
```bash
cd frontend
npm run test:unit
npm run lint
```
