# مراحل کلی اجرای پروژه

## بخش اول: برنامه‌ریزی (Plan)

این سند را کامل‌تر کن و برای هر یک از بخش‌های پروژه، برنامه‌ای با جزئیات تهیه کن. برای هر بخش، زیردامنه‌ها و گام‌های اجرایی را به‌شکل چک‌لیستی بنویس تا عامل هوش مصنوعی (Agent) بتواند پس از انجام هر مورد، آن را علامت بزند. همچنین برای هر بخش، آزمون‌ها و معیارهای موفقیت را مشخص کن.

یک فایل `AGENTS.md` نیز درون پوشه `frontend` ایجاد کن که کدهای موجود در آن پوشه را توضیح دهد.

اطمینان حاصل کن که کاربر برنامه را بررسی کرده و آن را تأیید می‌کند.

## بخش دوم: آماده‌سازی ساختار اولیه پروژه (Scaffolding)

زیرساخت Docker را راه‌اندازی کن، بخش بک‌اند را با استفاده از FastAPI در پوشه `backend/` ایجاد کن و اسکریپت‌های راه‌اندازی و توقف پروژه را در پوشه `scripts/` بنویس.

در این مرحله باید بتوان یک نمونه HTML ایستا (Static HTML) را اجرا کرد تا مطمئن شویم مثال «Hello World» به‌صورت محلی و روی سیستم کاربر به‌درستی اجرا می‌شود. همچنین باید یک فراخوانی API نیز انجام شود.

## بخش سوم: اضافه کردن فرانت‌اند (Frontend)

پروژه را به‌روزرسانی کن تا فرانت‌اند به‌صورت ایستا (Static) ساخته و ارائه شود؛ به‌گونه‌ای که تابلوی نمایشی کانبان (Demo Kanban Board) در مسیر `/` نمایش داده شود.

آزمون‌های واحد (Unit Tests) و آزمون‌های یکپارچه‌سازی (Integration Tests) را به‌صورت جامع پیاده‌سازی کن.

## بخش چهارم: اضافه کردن تجربه ورود آزمایشی کاربر (Fake User Sign-in)

پروژه را به‌روزرسانی کن تا کاربر هنگام ورود اولیه به مسیر `/`، پیش از مشاهده تابلوی کانبان، ملزم به ورود به سیستم باشد.

برای ورود، از اطلاعات کاربری آزمایشی زیر استفاده کن:

- نام کاربری: `user`
- رمز عبور: `password`

همچنین امکان خروج از حساب کاربری (Log out) را فراهم کن.

آزمون‌های جامع و کاملی برای این بخش بنویس.

## بخش پنجم: مدل‌سازی پایگاه داده (Database Modeling)

ابتدا ساختار پیشنهادی پایگاه داده (Database Schema) مربوط به کانبان را طراحی و آن را در قالب یک فایل JSON ذخیره کن.

روش و رویکرد مورد استفاده برای طراحی پایگاه داده را در پوشه `docs/` مستند کن و برای ادامه کار، تأیید نهایی کاربر را دریافت کن.

## بخش ششم: بک‌اند (Backend)

مسیرهای API را به بک‌اند اضافه کن تا امکان خواندن و تغییر اطلاعات تابلوی کانبان برای هر کاربر فراهم شود.

این بخش را به‌طور کامل و دقیق، با استفاده از آزمون‌های واحد بک‌اند (Backend Unit Tests) آزمایش کن.

اگر پایگاه داده از قبل وجود نداشت، باید به‌صورت خودکار ایجاد شود.

## بخش هفتم: اتصال فرانت‌اند و بک‌اند (Frontend + Backend)

فرانت‌اند را به‌گونه‌ای تغییر بده که واقعاً از API بک‌اند استفاده کند. در نتیجه، برنامه باید به یک تابلوی کانبان پایدار (Persistent) تبدیل شود؛ یعنی اطلاعات آن در بک‌اند و پایگاه داده ذخیره شود و با بارگذاری مجدد صفحه از بین نرود.

این بخش را به‌صورت بسیار دقیق و جامع آزمایش کن.

## بخش هشتم: اتصال به هوش مصنوعی (AI Connectivity)

امکان ارسال درخواست به یک سرویس هوش مصنوعی را از طریق OpenRouter به بک‌اند اضافه کن.

برای اطمینان از برقراری ارتباط، یک آزمون ساده با عبارت `2+2` انجام بده و بررسی کن که فراخوانی هوش مصنوعی به‌درستی کار می‌کند.

## بخش نهم: توسعه قابلیت ارتباط با هوش مصنوعی

فراخوانی هوش مصنوعی در بک‌اند را توسعه بده تا در هر درخواست، موارد زیر برای مدل هوش مصنوعی ارسال شوند:

- اطلاعات کامل تابلوی کانبان در قالب JSON
- سؤال کاربر
- تاریخچه مکالمه (Conversation History)

مدل هوش مصنوعی باید پاسخی با ساختار مشخص (Structured Outputs) تولید کند. این خروجی باید شامل پاسخ به کاربر و در صورت نیاز، یک به‌روزرسانی اختیاری برای تابلوی کانبان باشد.

این قابلیت را به‌طور کامل و دقیق آزمایش کن.

## بخش دهم: اضافه کردن دستیار هوش مصنوعی به رابط کاربری

یک ابزارک (Widget) زیبا در نوار کناری رابط کاربری (Sidebar) طراحی و پیاده‌سازی کن که از قابلیت گفت‌وگوی کامل با هوش مصنوعی (AI Chat) پشتیبانی کند.

این ابزارک باید به مدل زبانی بزرگ (LLM) اجازه دهد تا بر اساس تشخیص و تصمیم خودش، اطلاعات تابلوی کانبان را با استفاده از خروجی ساختاریافته (Structured Outputs) به‌روزرسانی کند.

اگر هوش مصنوعی تابلوی کانبان را به‌روزرسانی کرد، رابط کاربری باید به‌صورت خودکار تازه‌سازی شود تا تغییرات جدید را نمایش دهد.
