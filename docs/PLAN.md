# مراحل جامع و گام‌به‌گام اجرای پروژه کانبان هوشمند

این سند شامل نقشه راه کامل توسعه، چک‌لیست اقدامات اجرایی، آزمون‌ها و معیارهای موفقیت برای هر یک از بخش‌های ۱۰‌گانه پروژه است. بر اساس تصمیمات اتخاذشده، قابلیت‌هایی نظیر اولویت‌بندی کارت‌ها، جستجو، بازگردانی تغییرات هوش مصنوعی (Undo)، نگهداری تاریخچه گفت‌وگو در دیتابیس، دکمه‌های آماده چت، شمارنده و درصد پیشرفت به برنامه افزوده شده‌اند.

## بخش پنجم: مدل‌سازی پایگاه داده (Database Modeling)

### گام‌های اجرایی
- [ ] طراحی شمای پایگاه داده با پشتیبانی ساختاری از چندکاربره بودن در قالب یک فایل JSON در پوشه `docs/schema.json`.
- [ ] لحاظ کردن جداول و فیلدهای زیر:
  - جدول `users`: شناسه، نام کاربری، رمز عبور، تاریخ ایجاد.
  - جدول `boards`: شناسه، شناسه کاربر، عنوان تخته، تاریخ ایجاد و به‌روزرسانی.
  - جدول `columns`: شناسه، شناسه تخته، عنوان ستون، ترتیب ستون (order).
  - جدول `cards`: شناسه، شناسه ستون، عنوان، توضیحات، اولویت (بالا، متوسط، پایین)، ترتیب قرارگیری (order)، تاریخ ایجاد.
  - جدول `chat_messages`: شناسه، شناسه تخته/کاربر، نقش (user/assistant)، متن پیام، وضعیت تخته مرتبط (برای امکان Undo)، تاریخ ایجاد.
- [ ] نگارش سند تحلیلی مدل داده در پوشه `docs/DATABASE.md` شامل ارتباطات جداول و رویکرد مهاجرت.
- [ ] دریافت تأیید نهایی کاربر برای ساختار پایگاه داده.

### آزمون‌ها
- ارزیابی اعتبارسنجی فایل JSON شمای پایگاه داده.
- بررسی وجود روابط کلید خارجی (Foreign Keys) و شاخص‌ها برای عملکرد بهینه.

### معیارهای موفقیت
- ساختار داده کاملاً با نیازمندی‌های چندکاربره، اولویت‌بندی، ذخیره چت و عملیات بازگردانی همخوانی داشته باشد.
- مستندات مربوطه در پوشه `docs/` تکمیل و توسط کاربر تأیید شود.
