# LOOM (frontend)

Bilingual five-column Kanban MVP. State lives in the browser only and resets to sample data on reload.

From the repository root:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Run `npm test` for Vitest unit tests and Playwright e2e (`e2e/board.spec.ts`).
